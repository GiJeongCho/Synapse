# Synapse 구현 현황 및 실행 환경

> 마지막 갱신: 2026-06-23

---

## 1. 실행에 필요한 외부 서비스

### 필수

| 서비스 | URL / 포트 | 용도 | 비고 |
|--------|-----------|------|------|
| **Embedding API** | `http://ppsystem.kro.kr:5000/embed` | 텍스트 → 벡터 임베딩 | Milvus 적재·검색에 필수. `Qwen/Qwen3-Embedding` (dim=1024) |
| **Milvus Lite** | 로컬 `backend/synapse.db` | Vector DB | 파일 기반, 별도 프로세스 불필요 |
| **Anthropic API** | 클라우드 (API 키) | LLM 호출 | Meta-Agent, LLM 기반 청킹/분류에 필요. `.env`에 `ANTHROPIC_API_KEY` 설정 |

### 선택 (없어도 폴백 동작)

| 서비스 | URL / 포트 | 용도 | 폴백 |
|--------|-----------|------|------|
| **Rerank API** | `http://ppsystem.kro.kr:5000/rerank` | Cross-encoder 리랭킹 | API 미응답 시 `(검색점수 × 0.6) + (color_intensity × 0.4)` 가중합 |
| **Neo4j** | `bolt://localhost:7687` (Browser: `:7474`) | Graph DB | GraphStore 아직 미구현, docker-compose로 띄울 수 있음 |

### 개발 서버

| 서비스 | 포트 | 실행 |
|--------|------|------|
| FastAPI | `8000` | `uvicorn app.main:app --reload` (backend/ 에서) |
| Vite dev | `5173` | `npm run dev` (frontend/ 에서), `/api`→`:8000` 프록시 |

## 2. 환경 변수 (.env)

`Synapse/backend/.env` 에 설정 (없으면 기본값 사용):

```env

MILVUS_URI=backend/synapse.db
MILVUS_COLLECTION=synapse_chunks
NEO4J_URI=bolt://localhost:7687

NEO4J_PASSWORD=your_password

```

## 5. 동작 가능한 E2E 플로우

### 문서 → 검색 (동작함)

```
문서 업로드 → 전처리(분류/청킹/메트릭/정규화/스코어링)
           → 임베딩(embed API) → Milvus 저장
           → /api/search/query → hybrid_retrieve → rerank → 결과 반환
```

### Meta-Agent 에이전트 생성 (동작함)

```
POST /api/meta-agent/create
  → Registry 조회 (HIT이면 기존 에이전트 반환)
  → MISS: Solo 또는 Dual 모드
    Solo: 파이프라인 1회 (Requirements→Tool→Provision→Evaluate) → 등록
    Dual: Builder↔Critic 쌍방 진화 루프 → 합의 → 등록
```

### Multi-Agent 리서치 (아직 불가)

```
POST /v1/agent/execute/research → ❌ 미구현
  Supervisor → search/crawl/graph/analyst/writer → 리포트
```
